# 清掃会社向け基幹システム

## 概要

アナログで行っている勤怠・交通費・物品発注などの社内申請業務を Web 化するプロジェクト。  
全従業員を対象とし、3 ヶ月以内の導入を目指す。スマホ対応により出先からも申請可能。
